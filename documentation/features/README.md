# Features

> **Level: 🟢 Beginner.** One page per feature: what it does, why you would want it, and how it works underneath.

Every page follows the same order: **feature set** (what you get), **benefits** (why it matters to you), **technical
details** (how it works, for the curious and the suspicious). Stop reading wherever you have heard enough.

## Core features

The things Solarr is *for*. You meet all of them in the first hour.

| Feature | In one line |
|---|---|
| [Libraries and media types](libraries.md) | Music, TV, anime, movies, books, audiobooks, comics and manga (adult optional) in one app, as many libraries as you like |
| [Recognition and import](recognition.md) | Point it at any folder, any depth: it works out what is there, shows a preview, and can undo the lot |
| [Metadata](metadata.md) | Covers, posters, cast, ratings and descriptions from several providers per library, in an order you choose |
| [Hunting and downloads](hunting.md) | Finds what is missing and what could be better, within a budget, through your indexers and download client |
| [Quality](quality.md) | Judges the real file, not the release name; an upgrade must strictly win |
| [Files, folders and storage](storage.md) | Naming, many disks, one move engine, a recycle bin, and duplicates found and merged |
| [Moving over from the \*Arrs](arr-migration.md) | Reads your Lidarr, Sonarr, Radarr, Readarr, Whisparr and Prowlarr setup; only ever reads |

## Advanced features

Worth knowing about, not needed on day one.

| Feature | In one line |
|---|---|
| [Preview player](player.md) | Play anything in the browser; converted on the fly when the browser cannot |
| [Transcoding](transcoding.md) | Convert a library to its target quality in the background, originals kept and restorable |
| [Discover and import lists](discover.md) | Recommendations per library from the charts of its sources, previewed before anything is added |
| [Users and interface levels](users.md) | Several accounts, access per library, and a normal / advanced / expert interface |
| [Automation and activity](automation.md) | A scheduler you can watch, pause and explain; activity, history, calendar, statistics |
| [Media servers and webhooks](connections.md) | Tells Jellyfin and friends about new files; webhooks to Discord, ntfy, Gotify and more |
| [Privacy and security](privacy.md) | No telemetry, encrypted secrets, one guarded door for every outbound request |
