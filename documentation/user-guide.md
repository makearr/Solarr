# User guide

For people running Solarr, not developing it. New here? Start with **[Getting started](getting-started.md)**.

This page is the map. The guide is split by topic into [guide/](guide/); every page says at the top how much
of it a beginner can use.

## Interface levels

Every page of this documentation carries a level, and Solarr's own screens follow the same three steps
(**Settings → User → Interface level**).

| Level | In these docs | In the interface | Means |
|---|---|---|---|
| 🟢 **Beginner** | Run a library; no settings needed | **normal** | Add things, watch them arrive, fix what is flagged |
| 🟡 **Advanced** | Connections, import, storage, tuning | **advanced** | You decide where files go, how they are named and how hard Solarr searches |
| 🔴 **Expert** | Internals, caches, benchmarks, contributing | **expert** | You want to know why, or you are changing Solarr itself |

Inside a page, a heading tagged 🟢, 🟡 or 🔴 is that level's part; an untagged page uses the level at its top.
If a screen mentioned is missing, raise the level.

## What the colours mean

On posters and artist pages: 🟩 **green** complete · 🟥 **red** missing · 🟪 **purple** downloading · 🟨 **yellow**
not released yet · ⬜ **grey** unverified.
